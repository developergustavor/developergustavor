## 🧭 Princípios

| | Princípio | Na prática |
|:-:|---|---|
| 🛡️ | **Guardrails antes de autonomia** | Humanos revisam a saída da IA que importa; efeitos colaterais exigem aprovação |
| 🧪 | **Provar com testes** | TDD, E2E com Playwright, milhares de testes automatizados nos produtos |
| 🔎 | **Medir antes de confiar** | Telemetria, auditorias e checagem de dados — foi assim que o erro de 12 pontos apareceu |
| 💸 | **IA tem orçamento** | Custo por modelo, prompt caching, infraestrutura dimensionada |
| 🧩 | **Domínio primeiro** | DDD e arquitetura hexagonal; agentes são adaptadores, não a arquitetura |
| 🔐 | **Seguro por design** | E2EE, RBAC, IAM de menor privilégio, auditorias de segurança |
| ✅ | **Pronto é pronto** | Testes verdes, build limpo, revisão independente, docs atualizadas |
