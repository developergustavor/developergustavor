## 🧭 Principles

| | Principle | In practice |
|:-:|---|---|
| 🛡️ | **Guardrails before autonomy** | Humans review AI output that matters; side effects need approval |
| 🧪 | **Prove it with tests** | TDD, Playwright E2E, thousands of automated tests across products |
| 🔎 | **Measure before you trust** | Telemetry, audits and data checks — that's how the 12-point bug was found |
| 💸 | **AI has a budget** | Per-model cost tracking, prompt caching, rightsized infrastructure |
| 🧩 | **Domain first** | DDD and hexagonal architecture; agents are adapters, not the architecture |
| 🔐 | **Secure by design** | E2EE, RBAC, least-privilege IAM, security audits |
| ✅ | **Done means done** | Tests green, clean build, independent review, docs updated |
